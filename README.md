## 🧭 A tese em uma frase

99% das agências de IA entregam Loom + fatura + "qualquer dúvida me chama". Isso é o
*álcool gel em cima da mesa*: ninguém fotografa, ninguém indica. A ANi já tem a
**substância** (Código SERVIR + Método PGA); este playbook adiciona a **camada de
experiência** que faz o cliente querer registrar e compartilhar.

## 🏛️ O encaixe

- **A casa:** ANi | Alquimia Digital — consultoria, Código SERVIR, Método PGA, Constelação.
- **A porta de entrada:** **O Elixir** — produto-âncora viral (leads + CRM + Google Meu
  Negócio + auto-otimização) que conduz o cliente para dentro da consultoria completa.

## ✦ Os Sete Elementais (Constelação com pele comercial)

Cada mentor mantém o nome humano (a alma interna); a persona pública vira um **Elemental** —
força da natureza, não santo. Resolve a regra *"não usar espiritualidade como promessa"*.

## 🔄 Método PGA entregue como experiência

Cada etapa do método vira um momento-uau fotografável (problema e resultado **primeiro**):

1. **Perceber** → O Diagnóstico que dói de tão certeiro
2. **Governar** → As Regras do Jogo (transparência = Responsabilidade)
3. **Arquitetar** → A Planta Revelada (antes → depois)
4. **Agenciar** → Os Elementais Assumem
5. **Integrar** → A Primeira Transmutação (o "fogo na panqueca", ao vivo)
6. **Evoluir** → A Transmutação Contínua + O Diário da Pedra
